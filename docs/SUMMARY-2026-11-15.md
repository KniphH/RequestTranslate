# 这轮修了什么（2026-11-15，1.3.2）

## 一、已经解决

**面板与翻译**
- 划词后点 ↻ 不会再偷偷改为「读剪切板截图」；空态会提示你先划词或截图。
- 切换界面语言后，状态行、按钮悬停提示会真的跟着变（以前停在旧语言）。
- 「重试」和「重新翻译」拆成两句，不再共用一个词。

**火狐**
- 后台被系统回收后「扩展已更新，请刷新页面」卡死：会自动重连，不谎称完成。
- 重连计数会清零，不会攒几次就误报。
- bilibili 通道在火狐被风控：UA / Origin 改为写进配置模板，不再依赖浏览器专有 API。

**英文界面**
- 语言代码表说明、OCR 配置标题、「新供应商」「加一行」「恢复内置对照」
  「值（一行一个）」「收起」、popup 整页——都会跟着切。
- 根因：语言包不在安装包里，从仓库下载；你机器上还是旧包，缺新文案就回退中文。
  最新包已推到仓库，**重新选一次语言**即可下到新的。
- popup 顶部和底部重复的「打开设置」只留底部那个。
- 语言代码表那句说明现在也能「不再显示」。

**验证与打包**
- 同源检查能抓旧包，也能抓语言包被改（实测改一个值就报红）。
- 测试数字带时间戳和提交号，留档可复核。
- 修掉一个打包中断：清理旧目录时被系统删除保护打断。
- 全量 1824 项；zip / xpi 双包 29 个文件一致，且与源码逐文件对齐。
- 顺带修掉一条 e2e 假红：变量拖动后「固定等 600ms 读存档」改成轮询等落盘。

## 二、关于「lib 内部诊断文案」

`lib/` 是扩展内部的代码目录（你看到的面板、设置页、OCR 流程都由它驱动）。

「诊断文案」指两处：面板右上「…」展开后的 HTTP 状态 / 耗时 / 请求 / 响应，
以及失败时那句错误气泡。这些现在是中文。

要不要翻：**建议翻**（英文用户看到中文报错看不懂），但要改 16 个 lib 文件、加 240 多条 key，
属于单独一轮的活。我这轮没动，避免在错误路径上引入新 bug。你说做我就做。
