# 这轮修了什么、还剩什么（2026-11-15）

## 一、已经解决

**面板与翻译**
- 划词后点 ↻ 不会再偷偷改为「读剪切板截图」；空态会提示你先划词或截图。
- 切换界面语言后，状态行、按钮悬停提示会真的跟着变（以前停在旧语言）。
- 「重试」和「重新翻译」拆成两句，不再共用一个词。

**火狐专属**
- 后台被系统回收后「扩展已更新，请刷新页面」卡死的问题修好：会自动重连，不谎称完成。
- 重连计数会清零，不会攒几次就误报。

**英文界面（本次重点）**
- 语言代码表的说明、OCR 配置标题、「新供应商」「加一行」「恢复内置对照」
  「值（一行一个）」「收起」、popup 整页——以前都是中文，现在都会跟着切。
- 根因：语言包不在安装包里，从仓库下载；仓库那份更新了、你机器上还是上次下的旧包，
  新文案缺失就回退中文。最新语言包已推到仓库，**重新选一次语言**就会下到新的。
- popup 顶部和底部重复的「打开设置」只留底部那个。
- 语言代码表那句说明现在也能「不再显示」。

**验证与打包**
- 同源检查能抓旧包，也能抓语言包被改（实测改一个值就报红）。
- 测试数字带时间戳和提交号，留档可复核；数字过期会直接判失败。
- 修掉一个打包中断：清理旧目录时被系统删除保护打断。
- 全量 1820 项全绿；zip / xpi 双包 29 个文件一致，且与源码逐文件对齐。

## 二、仍需注意

1. **真实接口没实测**：Bing / DeepL / 各家模型的限流、Key 过期、异常响应，只有本地假接口。
2. **火狐只验了包形态**：事件页回收、重连、bilibili 通道需要真机装包确认。
3. **视觉细节**：间距、对齐、暗色对比断言看不出来，需要人眼。
4. **lib 内部诊断文案仍是中文**：英文界面下错误气泡 / 诊断行是中文（已定口径，不影响主要界面）。
5. **没推送、没改版本号**：本地已闭环，发版由你决定；装新包后需要「重新加载扩展」。
