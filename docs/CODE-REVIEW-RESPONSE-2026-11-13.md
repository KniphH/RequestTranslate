## 二、P0-2 `T()` 丢参

content.js 的 `T(key, fallback)` 只有两个形参，而 options.js 同名函数早就三参了。
于是十几处带 `$1$` 的文案（「已切到「$1$」，点 ↻ 翻译」「翻译中…（$1$ 条）」）

修：补第三参；语言包没这条时兜底文案也要替换；
顺带把 4 处手工 `.replace('$1$', …)` 改成正式的 params。

## 三、P0-3 `setDot` 第二参被吞

`setDot(kind)` 只接一参，而 `:950` 调的是 `setDot('', T('dot_idle_tip','空闲'))`。
第二参丢了，`dotTip('')` 落进 err 分支 ——
**后台被回收的收尾反而把灯标成「翻译失败」**。

修：`setDot(kind, tip)` 接第二参；`dotTip` 增加「kind 为空 → 空闲」。
