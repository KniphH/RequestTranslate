## 六、发版流程

1. 改 `manifest.json` 的 `version`
2. `python tools/pack.py --xpi`（内部跑全量）
3. `python tools/verify-pack.py dist/<zip>` 与 `.xpi`，都应「全部通过」
4. 推送 git、挂 GitHub Release（附 zip + xpi）
5. 商店：Edge 传 zip、Firefox 传 xpi（需手动登录后台上传）
