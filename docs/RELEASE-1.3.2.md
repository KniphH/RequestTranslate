# RequestTranslate 1.3.2

> 本次是稳定性与多浏览器修复，不改配置格式，升级后原有配置 / 变量 / Key 全部照常。

## 修复

- **火狐：后台被回收后卡在「扩展已更新，请刷新页面」**
  火狐的 MV3 后台是事件页，空闲约 30 秒会被回收、端口随之断开。现在自动重连；
  请求确实丢了会明确说「请重新翻译一次」，不再谎称完成，也不再卡死。
- **火狐：bilibili 通道必被风控**
  把 `User-Agent` / `Origin` 直接写进配置模板，不再依赖浏览器扩展 API（火狐上没有那条规则）。
- **右键菜单全空**
  i18n 改造时漏改 3 处调用，导致建菜单时抛错。已修，并加了「改名要扫全文件」的断言。
- **英文界面夹中文**
  语言包不在安装包里（保持体积极致轻量），从仓库下载；旧包缺新文案时会回退中文。
  语言包已更新：**在设置页重新选一次语言**即可拿到完整英文。
- **popup 整页没翻译**、顶部和底部重复的「打开设置」——已修，只留底部入口。
- **面板 ↻ 在空态会去读剪切板截图**——改为提示「先划选文字，或用截图翻译」。
- **切换语言后状态行 / 悬停提示还是旧语言**——现在会跟着重算。
- **设置页白屏**（开发过程中引入又修掉）：初始化抛错时整页只剩一句报错。已补回并加了白屏检测断言。

## 安装 / 升级

- Edge / Chrome：加载 `request-translate-1.3.2.zip` 解压后的文件夹（或等商店更新）。
- Firefox：安装 `request-translate-1.3.2.xpi`。
- **升级后请重新加载扩展，并在设置页重新选一次界面语言**（语言包是下载的，不吃旧缓存）。
