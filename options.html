自定义变量

        

          这里定义的值可以在请求模板里用 {{名字}} 引用，比如把 API Key 写成
          Bearer {{apiKey}}。同名的话，下面这些会覆盖内置变量。
          

          值里一行写一个时（模板里用到的那个含 model 的变量，比如
          model / GEMINI_MODEL），翻译会从第一个开始试，
          哪个先返回译文就用哪个；只有一行就是普通单值。

翻译按钮


        

          
          

            

              

              

                

                预览
              

            

            

              划词后出现在选区旁边那个小按钮的样子，只影响按钮本身。地球是线性图标，颜色跟着
              主题走；自定义不给底座 —— 整块就是你粘进下面那段 SVG。
            

          

        


        

          
          
        


        

          
          

            
            

              出现后鼠标一直不动，过这么多秒就自己消失（鼠标动一下、或者停在按钮上，都不算）。
              填 0 = 不消失。
            

          

        


        

          
          

            
            

              鼠标从按钮上移开、又没点，过这么多秒就消失；移回去就不消失。填 0 = 这项不生效。
            

          

        


        

          
          

            
            

            

              粘 <svg>…</svg> 进来，替换掉预设里的图标 /「译」字；
              底座还是用上面选的那个预设，想连底座都自己说了算就选「自定义」。
              颜色写 currentColor 跟着主题走。

              这段会插进页面，所以要求以 <svg 开头、</svg> 结尾，
              且不含 <script> / onload= / href /
              <foreignObject> 这类东西 —— 不通过时下面会说明卡在哪一条（内容不会被改）。
