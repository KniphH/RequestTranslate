RequestTranslate

配置就是一段请求，参数怎么摆你说了算

配置列表 可拖动排序

支持 curl 与原始 HTTP 报文两种写法，除占位符外一字不改地发出去。 JSON 字符串内不能有裸换行，换行写 \n，双引号写 \"。 行首 # 是注释，引号内的 # 不受影响。

翻图专用的一段。右键「翻译剪切板中的截图」、且 OCR 栏勾了「禁用外置 OCR」时用这一段； 普通划词翻译用上面那段。两段互不干扰，可以放心把这段写成多模态的样子： {"role":"user","content":[{"type":"image_url","image_url":{"url":"{{image}}"}},{"type":"text","text":"把图里的文字翻成{{target}}，只输出译文"}]}
留空就回退到上面那段（那时 {{image}} 是空的，所以只写了文字模板也不会坏）。 这段里 {{text}} 始终是空串 —— 直接翻译时，图片本身就是原文。 上面那排 text / image / target … 标签会插进当前光标所在的框。

点号 + 下标，例如 data.translations[0].translatedText。留空时会依次尝试各家常见的返回结构。

                预览
              

            

            

              划词后出现在选区旁边那个小按钮长什么样。只影响按钮本身，不动结果面板。
              地球是线性图标，颜色跟着上面的主题走；自定义不给底座 ——
              整块就是你粘进下面「自定义图标」的那段 SVG（想要圆盘 / 方块，自己在 SVG 里画一个）。
              自定义那张卡上的图标就是你实际会用的那个：填了显示你的，没填先空着。
            

          

        


        

          
          
        


        

          
          

            
            

            

              粘一段 <svg>…</svg> 进来，它会替换掉预设里的图标 /「译」字；
              底座（底色、圆角、大小）还是用上面选的那个预设 ——
              想连底座也自己说了算，样式就选「自定义」（那个预设没有底座）。
              颜色写 currentColor 就跟着主题走（暗色浅紫 / 亮色深紫），写死颜色也行。
              

              这段代码会被插进页面，所以要求以 <svg 开头、</svg> 结尾，
              且不含 <script> / onload= / href /
              <foreignObject> 这类东西 —— 通过时下面会绿字写一句「这段用上了」，
              不通过时会说明卡在哪一条（内容不会被改，是整段不用）。
