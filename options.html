自定义变量

        

          这里定义的值可以在请求模板里用 {{名字}} 引用，比如把 API Key 写成 Bearer {{apiKey}}。同名的话，下面这些会覆盖内置变量。
值里一行写一个时（模板里用到的那个含 model 的变量，比如 model / GEMINI_MODEL），翻译会从第一个开始试，哪个先返回译文就用哪个；只有一行就是普通单值。

          翻译按钮
          


        

          
          

            

              

              

                

                预览
              

            

            

              划词后出现在选区旁边那个小按钮的样子，只影响按钮本身。地球是线性图标，颜色跟着主题走；自定义不给底座 —— 整块就是你粘进下面那段 SVG。
            

            

          

        


        

          
          
        


        

          
          

            
            

              出现后鼠标一直不动，过这么多秒就自己消失（鼠标动一下、或者停在按钮上，都不算）。填 0 = 不消失。
            

            

          

        


        

          
          

            
            

              鼠标从按钮上移开、又没点，过这么多秒就消失；移回去就不消失。填 0 = 这项不生效。
            

          

        


        

          
          

            
            

            

              粘 <svg>…</svg> 进来，替换掉预设里的图标 /「译」字；底座还是用上面选的那个预设，想连底座都自己说了算就选「自定义」。颜色写 currentColor 跟着主题走。
            

            

              
              
            

          

        
          

        



          面板
          



        
        

          
          

            

              
            

            
浮出来的就是**网页上那个真面板**：样式、顶栏、拖动、✕ 关闭全都一样，跟着上面的宽度 / 字号 / 高度 / 主题实时变。里面的文字是示例内容。

          

        

        
        

        

          
          
        


        

          
          
        


        

          
          

            
            

              只在上一条是「自适应」时有用：译文太长时正文区到这儿就不再长，多出来的滚着看。单位 vh（窗口高度的百分之几），默认 46；填 0 = 不限。
            

          

        


        

          
          
        


        

          
          
        



        

          
        


        

          
          

            
            

              
              
            

            

              这段 CSS 会注入到面板自己的 shadow root 里。面板不在页面 DOM 中，所以把它贴到 Stylus / user.css 是无效的 —— 只能写在这儿。
可用的钩子：#rt-panel（面板本体，id 选择器优先级高于预设，一般不用 !important）、[data-rt-theme="dark"] 与 [data-rt-theme="light"]（按主题分别写）、.rt-head .rt-cfg .rt-lang .rt-out .rt-src .rt-slot .rt-slot-h .rt-slot-name .rt-slot-b .rt-acts .rt-act .rt-foot .rt-msg .rt-more .rt-diag .d-k .d-v .rt-btn .rt-dot。这些名字不会改（真要改会给别名）。
            

          

        

          

        


        

          导入 / 导出
          


        

          
          

            

              
              
            

            
备份版里有明文 API Key，只发给你自己。勾上「加密导出」则用口令加密（AES-GCM）—— 口令不恢复，丢了文件就解不开。

          

        


        

          
          

            
            
自动清空名字里含 key 的变量值，发给别人填他自己的 Key。请求模板正文里手写的 Key 不会被自动发现，分享前自己检查一遍。

          

        


        

          
          

            
            
整体替换当前的配置、变量、设置和 OCR。加密的文件会先问口令。
