# RequestTranslate

划词翻译扩展，但**配置不是一堆输入框，而是一整段请求文本**。

写什么发什么。

## 首次使用

**开箱即用**

内置的第一条配置是 **Bing 翻译（免费 · 无需 Key）**，默认选中。任意网页划词，出现一个按钮，点击即可翻译

使用自定义模型：

1. 设置页 → **变量** 标签 → 把 `apiKey` 的值填成你自己的 key，如需使用多个供应商，可保存多个key
2. 回 **配置** 标签，选择内置示例（OpenAI / DeepSeek / DeepL / Ling / Ollama / Anthropic）修改
3. 点 **发送** 测试

**翻译截图**：截图，右键 →「翻译剪切板中的截图」
默认为硅基流动的 **DeepSeek-OCR**（免费，填个key即可，返回结果按当前配置翻译 —— 见 [翻译截图（OCR）](#翻译截图ocr)

## 写配置

### 请求模板

一整段文本，两种写法任选。

**curl 写法** —— 直接从文档复制。支持：

| 写法 | 说明 |
| --- | --- |
| `-H "K: V"` / `--header` | 请求头 |
| `-d '…'` / `--data-raw` / `--data-binary` | 请求体，多个会拼起来 |
| `-X POST` / `--request` | 方法。不写的话：有 body 当 POST，没有当 GET |
| `-u user:pass` | 自动生成 `Authorization: Basic …` |
| `-G` | 把 `-d` 的数据并到 URL 的 query 上 |
| `-A` / `-b` / `-e` | User-Agent / Cookie / Referer |
| `\` 换行 | 续行 |
| 行首 `#` | 注释，会被忽略 |

**原始 HTTP 报文写法** —— 不想写 curl 就直接写：

````
POST https://api.anthropic.com/v1/messages
x-api-key: {{apiKey}}
anthropic-version: 2023-06-01
content-type: application/json

{
  "model": "claude-3-5-haiku-latest",
  "max_tokens": 2048,
  "messages": [{"role": "user", "content": "{{text}}"}],
  "stream": true
}
````

第一行是「方法 + URL」，接着是 header，空行之后全是 body。

一条配置还能写第二段 **图片请求模板**，只在右键翻截图、并且勾了「禁用外置 OCR」时用，留空就回退到普通那段。见 [翻译截图（OCR）](#翻译截图ocr)。

### 占位符

模板里的 `{{...}}` 会被替换掉，只有这些位置会动，其余一个字节不改。

| 占位符 | 值 |
| --- | --- |
| `{{text}}` | 选中的文字（也可以用 `{{selection}}`）。截图直传时是空串 |
| `{{image}}` | 截图翻译时那张图的 data URL；普通划词翻译时是空串 |
| `{{imagePart}}` | 上面那张图对应的**一整段 content 元素**（含前导逗号）；没图时是空串 |
| `{{target}}` | 设置里的目标语言，默认「简体中文」，**原样**搬进来（给聊天模型看） |
| `{{targetCode}}` | 同一件事，但映射成接口要的大写代码：简体中文 → `ZH-HANS`、日语 → `JA`。给 DeepL 这类只认代码的接口用 |
| `{{targetLang}}` | 同 `{{target}}` |
| `{{url}}` / `{{title}}` | 所在页面的地址 / 标题 |
| `{{date}}` | 今天的日期 |
| `{{任意名字}}` | 你在 **变量** 标签里定义的值，比如 `{{apiKey}}` |

**会自动转义**，按占位符**落在哪几层引号里**从内到外逐层来（不是看它两侧紧挨着什么字符）：

| 模板里写成 | 落在一层 | 效果 |
| --- | --- | --- |
| `"{{text}}"` 或 `{"content":"…{{text}}…"}` | JSON 字符串 | JSON 转义（`"` → `\"`，换行 → `\n`） |
| `'{{text}}'` | shell 单引号 | shell 转义（`'` → `'\''`） |
| `-d '{"content":"…{{text}}…"}'` | **两层** | 先 JSON 转义，再 shell 转义 |
| `{{text}}` | 不在引号里 | 原样插入 |

所以选中一段带引号、带换行的文字，也不会把 JSON 撑破。

**`-d '…'` 这种 curl 模板是两层，最容易踩**：漏了转义，文本里一个撇号就能把外层引号提前闭合、请求体被截断，接口只回
`JSON parse error: Unexpected end-of-input in VALUE_STRING`。翻英文几乎必然踩到（`Pixeldrain's`、`There's`…）。

> 设置页「渲染预览」里，两层引号中的占位符会显示成 `'\''` 这种 shell 拼接写法 —— 那是它要被 shell 解析的原样。

### 响应提取路径

留空就行，会依次尝试各家常见结构：

```
choices[0].message.content      OpenAI / DeepSeek / 大部分中转
choices[0].delta.content        OpenAI 流式
delta.text                      Anthropic 流式
content[0].text                 Anthropic 非流式
candidates[0].content.parts[0].text   Gemini
message.content                 Ollama
data.translations[0].translatedText   Google 翻译
translations[0].text            DeepL 官方 API（自建 DLX 的 /v2/translate 也是这个壳）
```

要是某个服务结构比较特别，手动填路径。语法是 `点号 + 下标`：

```
data.translations[0].translatedText
output.choices[0].text
["奇怪的 key"].value
```

设置页右下角的 **发送** 会把 HTTP 状态、耗时、命中的路径、提取结果、原始响应全列出来，对不上了一眼就能看出来。

## 结果面板

```
┌────────────────────────────────────────────┐
│ ● [配置 ▾] [语言 ▾]           👁  ↻  ⧉  ✕ │ ← ● 是状态灯，👁 切换原文显示
├────────────────────────────────────────────┤
│ 原文（可隐藏，和设置页那个开关是同一个）      │
├────────────────────────────────────────────┤
│ 译文，流式吐出来                            │
├────────────────────────────────────────────┤
│ HTTP 200 · 1.4s · choices[0].delta.content … │ ← 「…」是详细诊断
└────────────────────────────────────────────┘
```

| 部位 | 说明 |
| --- | --- |
| 状态灯 | 透明 = 还没发请求，**紫** = 请求在飞，**绿** = 拿到译文，**红** = 失败。亮着的三态都带同色辉光，悬停有说明。**绿灯只说这次请求成功了**，带警告（有变量没喂上、返回体不是合法 JSON）照样绿灯，警告在状态栏和 `…` 里标黄 |
| 配置下拉 | 翻过的切回来直接放回上次结果（连灯和诊断，**一个请求都不发**）；没翻过的当场翻一次。↻ 是**重发同一条请求**。重新划词时旧结果整批作废 |
| 语言下拉 | 和设置页的目标语言是同一个值。拨一下**当场用新语言重发**，各配置缓存里的旧译文作废 |
| 👁 | 显示 / 隐藏原文，和设置页那个开关是同一个值 |
| 状态栏 | **HTTP 状态 · 总耗时 · 命中路径** |
| `…` | 详细诊断，见下 |

点 `…` 展开：

| 字段 | 意思 |
| --- | --- |
| **首字** | 第一个**译文**分片出现的时间。你实际等的就是它，不是总耗时 |
| 总耗时 | 从发出请求到流结束 |
| 响应格式 | 自动判定出来的：`SSE` / `JSON` / `NDJSON` / `TEXT` |
| 分片 | 一共收到多少个数据块 |
| 响应大小 | 收到多少字节 |
| 命中路径 | 译文是从响应里的哪个字段取出来的 |
| 模型思考 | 有值就说明模型在偷偷思考（`reasoning_effort` 没生效），标黄 |

**「模型思考」不为 0 时，`…` 按钮自己会变黄** —— 不用展开就知道有问题。实测同一句话：

| | 首字 | 思考字数 | 响应大小 |
| --- | --- | --- | --- |
| `reasoning_effort: "none"` | 0.79s | 0 | 2.3 KB |
| 不带这个参数 | 5.00s | 1454 | 46 KB |

**流式吐字时不抢滚动条**：视口原地不动，文字往后面接，照着原位从头读；想追最新的自己往下拖。

**小圆点贴选区末尾那个字的右下角**，不是整个选区外框的右下角 —— 跨行选中时外框右边界会跑到最长那一行末尾，离你松手的地方可能很远。倒着拖选（鼠标停在选区开头）时反过来贴开头。

**面板四个方向都夹在视口里**，拖不出去，正文变长时会自动把自己拉回来；网页缩放不影响它的实际大小。

### 配置列表

左栏那几条配置可以改顺序：**按住左边的手柄上下拖**，或者**点右边的 ↑ ↓**。

右键菜单、工具栏弹窗、划词面板顶栏的配置下拉**都按这个顺序排**，常用的挪到最上面。首尾两行的 ↑ / ↓ 是禁用的；只点一下手柄（晃 2px 以内）不会误排序。顺序会连导出 JSON 一起带走。

### 导出 / 导入（换台设备）

设置页右上角两个按钮。导出的是**整份存档**：全部配置（连顺序）、变量、设置、OCR 供应商。

> ⚠️ **文件里是明文 API Key**（翻译的、OCR 的都算）。它是「你自己换设备用」的备份，不是分享用的配置文件 —— 要发人之前先把 `apiKey` 清掉。

导入是**整体替换**，确认框会告诉你文件里几条、当前几条、导出于何时。拿别的软件的 JSON 进来会直接拒绝，手写的 JSON 也认（只要有 `configs` 数组）。

### 翻译按钮

| 预设 | 长什么样 |
| --- | --- |
| **译字方块** | 紫色渐变圆角方块 + 一个「译」字（默认） |
| **地球** | 正圆底 + 线描地球（带经纬线） |
| **自定义** | **没有底座** —— 整块就是你粘进来的那段 SVG |

大小单独调（20–96px）。地球的颜色跟着**主题**走（暗色下浅紫、亮色下深紫）。

想用自己的图标，在 **自定义图标（SVG）** 里粘一段自己画的 `<svg>…</svg>`：

```html
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.8">
  <path d="M4 12h10M9 7l5 5-5 5"/>
</svg>
```

- 选**地球 / 译字方块**：这段 SVG 只换**图标**（「译」字或地球被顶掉），底座（底色、圆角、描边）还是预设的
- 选**自定义**：底座全不要（底色 / 描边 / 阴影清零），整块就是你粘的 SVG
- **自定义还没填图标**：设置页那张卡片空着，页面上的按钮用示例图标（三线 + 箭头）占位并提示「还没填图标」

颜色写 `currentColor` 就跟着主题走（暗色浅紫 / 亮色深紫）。设置页右边有**实时预览**，和真实按钮是同一份样式表，所见即所得；下面还有「插入示例图标」可以直接拿去改。

SVG 最终是 `innerHTML` 插进页面的，所以做**白名单式整段校验**，不通过就**整段不用**（并告诉你卡在哪一条）：

| 要求 | 为什么 |
| --- | --- |
| 以 `<svg` 开头、以 `</svg>` 结尾 | 免得把整段 HTML 塞进来 |
| 不含 `<script>` / `<foreignObject>` / `<iframe>` / `<image>` / `<use>` / `<a>` / `<style>` / `<animate>` / `<set>` | 这些能执行代码或拉外部资源 |
| 不含 `onload=` / `onclick=` 这类事件属性 | 同上 |
| 不含 `href=` / `xlink:href=` | 外链 |

### 翻译截图（OCR）

用系统截图（Win + Shift + S 之类）截一张图，图片就进了剪切板。在任意网页上**右键 →「翻译剪切板中的截图」**，扩展会把它认成文字，再按「配置」里当前那条翻译出来。

剪切板里第一项不是图片时会直接告诉你「剪切板里没有图片」，不会拿一段文字硬翻。这条菜单和「翻译选中内容」**各有一个开关**。

**供应商在设置页的「OCR」标签里管。** 和「配置」一样是一张列表，可以填接口地址、模型、API Key，能新建 / 复制 / 删除。默认给了两条：

| 内置 | 接口 | 模型 | 费用 |
| --- | --- | --- | --- |
| 硅基流动 | `api.siliconflow.cn/v1/chat/completions` | `deepseek-ai/DeepSeek-OCR` | 免费 |
| OpenAI 兼容（VL） | `api.openai.com/v1/chat/completions` | `gpt-4o-mini` | 要钱 |

要的是一套 **OpenAI 兼容的 `chat/completions`**：截图以 data URL 塞进 `messages[0].content` 的 `image_url`，文字从 `choices[0].message.content` 取。这条路不让你手写模板（形状是固定的），但**整条请求在设置页里摊开给你看** —— 「这次会发出去的请求」里方法 / 地址 / 请求头 / 请求体都在（Key 打码），改哪个字段它就跟着变。

**提示词按模型填，插件不给预设。** 各家的格式互不相通（DeepSeek-OCR 认 `Free OCR.`、PaddleOCR-VL 认 `OCR:`）；这类接口对不认识的提示词大多**不认也不报错**，只表现为认出来的东西不对，换模型时记得连提示词一起换。

**「最大输出长度」（`max_tokens`）建议留空** —— 留空就不发这个字段，由服务端按模型自己的上限定。写死会在上下文窄的模型上直接 400，比如 `deepseek-ai/DeepSeek-OCR` 的 `max_seq_len` 只有 8192：

```json
{"code":20015,"message":"max_tokens (8192) have exceeded max_seq_len (8192) limit.","data":null}
```

确实要限长再填，填的数得给提示词留出余量。

**外面（右键菜单）不给你挑供应商**，用哪条只看设置页里选中的那一条。

#### 配好了先在设置页测一下

「OCR」那一栏底下和「配置」栏一样有个**测试**：不选文件就直接读**剪切板里的第一张图**，也可以先挑一张本地图片。点一下会真发一次请求，把 **HTTP 状态 / 耗时 / 图片大小 / 识别到的文字 / 实际请求 / 原始响应**全摊在页面上 —— 这里能出字，右键就一定也能。勾了「禁用外置 OCR」时这个按钮会变灰。

#### 禁用外置 OCR：把图片直接交给模型

如果你当前那条配置对应的模型**自己就能看图**（多模态），勾上「禁用外置 OCR」就不做识别了：截图被**原样塞进当前那条翻译请求**，由模型自己看图 + 翻译，省一次来回。

这时给这条配置写**第二段模板**（「配置」栏里那个 **图片请求模板**）就行，普通那段继续翻文字：

```json
{"role":"user","content":[
  {"type":"image_url","image_url":{"url":"{{image}}"}},
  {"type":"text","text":"把图里的文字翻成{{target}}，只输出译文"}
]}
```

| 你怎么操作 | 用哪段模板 | `{{text}}` | `{{image}}` |
| --- | --- | --- | --- |
| 划词 / 右键「翻译选中内容」 | 普通那段 | 选中的文字 | 空串 |
| 右键「翻译剪切板中的截图」+ 勾了禁用外置 OCR | **图片那段** | 空串（图片就是原文） | 那张图的 data URL |
| 右键「翻译剪切板中的截图」，没勾 | 普通那段 | OCR 认出来的文字 | 空串 |

**图片模板留空就回退到普通那段**，只写一段、或者老配置都不会出问题。直传那一次，结果面板会写明「这张截图直接发给了模型，没有先做外置 OCR」。

#### 只想写一段？用 `{{imagePart}}`

不想维护两段模板的话，`content` 写成数组、末尾挂一个裸的 `{{imagePart}}` 也能一段两用：

```json
{"role":"user","content":[{"type":"text","text":"仅输出{{target}}译文：\n\"\"\"\n{{text}}\n\"\"\""}{{imagePart}}]}
```

没图时它是空串（和原来等价），有图时它变成 `,{"type":"image_url","image_url":{"url":"data:…"}}`。

两个注意点：**必须裸着写**（套上引号会被当字符串转义，整段 JSON 就坏了），而且**只能放数组最后一项** —— JSON 数组第一项前面不能有逗号，占位符没法知道自己是第几个。想把图片放最前，就用上面那两段模板的写法。

## 常见问题

### Bing 免费通道

内置的 Bing 翻译不用 Key、不用配置，有三件事值得知道：

- 第一次翻译要抓一次页面（约 **1.5 秒**），之后 token 缓存一小时，单次 **0.8～1.2 秒**
- **开着代理时可能翻不出来**（HTTP 200 但内容是空的），解决办法见下
- 单次上限 1000 字符（国内 5000）；语言取设置里的目标语言，认「简体中文 / 繁體中文 / 英语」这些名字，也认 `zh-Hans` / `ja` 这种代码，认不出的回退简体中文

译文质量不如大模型，胜在零配置、不要钱。

### 代理与 Bing 免费通道

**开着代理时 Bing 的翻译接口可能用不了** —— 它会稳定回一个**空 body**（HTTP 200，但内容是空的），换个节点也一样：节点把这个接口掐了。改一次代理软件的规则就能解决，插件这边不用做任何设置。

用**能自定义规则 / 覆写脚本**的代理客户端（mihomo / Clash 系及其各种客户端），把这组规则加进去，并且**排在 `GEOSITE,microsoft` 这类分组规则之前**（规则自上而下匹配，排在后面就永远轮不到它）：

```
# Bing 翻译（主模式）：/translator 取 token → /ttranslatev3（有的库还会打 /tspellcheckv3）
DOMAIN-SUFFIX,bing.com,DIRECT
DOMAIN-SUFFIX,bing.net,DIRECT
DOMAIN-SUFFIX,bing.com.cn,DIRECT
DOMAIN-SUFFIX,bingj.com,DIRECT

# 微软翻译的另外两种端点：Edge 免费端 / Azure 付费端
DOMAIN-SUFFIX,edge.microsoft.com,DIRECT
DOMAIN-SUFFIX,microsofttranslator.com,DIRECT
DOMAIN-SUFFIX,microsofttranslator-int.cn,DIRECT
```

本插件的 Bing 适配器**只打 `cn.bing.com` 两处**，所以第一条就够；后面几条是给**同一个客户端里其它用 Bing / 微软翻译的工具**留的，多写没有副作用。

**为什么不能只放行翻译那一个接口：** 这类接口是两步的（先取 token，再拿 token 去翻译），token 跟这次会话绑在一起 —— **取 token 和用 token 的出口不一致就失效**。不存在「取 token 走代理、翻译请求走直连」这种半拉子分流。

> **副作用：Bing 搜索也会跟着直连。** 规则只能按域名匹配、不能按路径，做不到「只让翻译接口直连、Bing 搜索走代理」。写 `bing.com` 就是整站直连，搜索结果会变成 `cn.bing.com` 的国内版。如果你之前特意用代理拿 Bing 的国际结果，这里得权衡一下。

> TUN / 虚拟网卡模式也照样有效 —— 判的是连接发起的时刻，比「改浏览器代理设置」那类办法更彻底。

### 提示词里的换行

**JSON 里不能有裸换行**（这是 JSON 的规矩）。提示词要写成：

```
"content": "仅输出{{target}}译文：\n\"\"\"\n{{text}}\n\"\"\"\n输出示例：\nThe translated text itself"
```

模型实际收到的会是：

```
仅输出简体中文译文：
"""
原文内容
"""
输出示例：
The translated text itself
```

内置配置就是这么写的，照着改就行。忘了转义也不至于崩 —— 插件会尝试自动修复（剥掉注释行、把裸换行转义成 `\n`）并在结果里提示你。

### 模型先「思考」再作答

**混合推理模型（Ling-3.1、DeepSeek-R 这类）默认先吐一大段推理再给答案**，翻译场景要把这个关掉，否则你看到的就是「半天不出字」。实测 Ling-3.1-flash 翻一句话：

| 写法 | 首个思考分片 | 首个**译文**分片 | 输出思考字数 |
| --- | --- | --- | --- |
| 不带任何参数（默认） | 0.5s | **7.2s** | 2354 |
| `"reasoning": {"effort": "none"}` | 0.7s | **7.3s** ← 没生效 | 2185 |
| `"reasoning_effort": "none"` | —— 从不出现 | **0.5s** | 0 |

关掉思考用的是**顶层** `reasoning_effort`：

```
"reasoning_effort": "none"
```

**别写成 `"reasoning": {"effort": "none"}`。** 那个嵌套写法是 Vercel AI Gateway 这类中转自己桥接出来的，`api.ant-ling.com` 直连不认 —— 而且**不报错，静默忽略**，你会以为关了、其实思考照跑。参数名对不上时接口不会提醒你，只能实测。

想验证关没关干净，看结果面板 `…` 里的「模型思考」：0 就是关干净了，有数字就是没生效。要留一点思考，`"reasoning_effort"` 也接受 `"low"` / `"medium"` / `"high"`，思考内容不会混进译文。

### 改不了的 header

浏览器规定 `Host`、`Content-Length`、`Origin`、`Cookie`、`User-Agent` 这些由浏览器自己管，写在模板里会被忽略。需要鉴权的用 `Authorization` / `x-api-key` 这类正常的头。

### 跨域

不用担心。请求实际发生在扩展后台，有 `host_permissions: <all_urls>`，不受页面 CORS 限制。

### API Key

存在 `chrome.storage.local` 里，**明文，没加密**。别把导出的配置文件分享出去。

## 限制

- 只在顶层文档划词，iframe 里的选区拿不到
- 面板是覆盖层，页面全屏播放视频时会看不见
- 不支持 `-F` 上传文件、`-d @file` 这类需要文件系统的 curl 参数
- 没有快捷键，只有划词小圆点 / 右键菜单 / 弹窗三种入口
- **翻译截图只认剪切板里的第一项图片**，而且只在这台机器上浏览器能读剪切板时才行 —— 系统级剪贴板管理软件有时会把图片转成别的形态，那就读不到了
- **截图翻译的供应商只能在设置页选**，右键菜单里不给临时切
